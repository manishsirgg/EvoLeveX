# PR #291 — Restricted issuer/worker admission against real Store tables

This is an isolated disposable PostgreSQL 15/17 integration test. It extends the Store reconciliation test after a real synthetic checkout/intent/provider attempt has entered `reconciliation_required`. Two distinct PostgreSQL LOGIN roles, `evo_real_issuer_291` and `evo_real_worker_291`, have mutually exclusive EXECUTE rights on test-schema SECURITY DEFINER functions. Both functions independently lock and verify membership in the **actual** `public.user_roles` / `public.roles` tables and the **actual** `private.evo_store_provider_order_attempts` state. Tickets are 256-bit hex strings stored as SHA-256 digests, expire based on database time in 30 seconds, and can be consumed only once. Tests cover cross-role call denial, replay and revoked administrator membership at issuance and consumption. Administrator membership is restored for existing correlation checks.

**Not yet complete:** the test uses database-owner setup to seed the Store attempt and separate test functions; the ticket consumer does **not** execute `private.execute_evo_store_correlation_atomically`. Issuer login credentials alone can request a ticket for any real authorized operator: a trusted, independently verified administrator-to-issuer binding and audit remain mandatory. Ticket consumption is therefore not proof of authenticated administrator intent. Integrating genuine provider evidence, real nonce and correlation in the same ticket-consumption transaction is also pending. No real worker is connected.

No production migration, credentials, schema permission change, live Razorpay payment initiation/capture or Printful fulfillment. The owner-only correlation functions and always-false database proof gate remain unchanged.
